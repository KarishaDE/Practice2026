# Задача 15. Исследование многопоточного вычисления интеграла

Исследование выполняется для функции `sin(x)` на отрезке `[-100; 100]`.

## Состав работы

- `PerformanceResearch.cs` — многократные замеры с помощью `Stopwatch`;
- `ResearchOutput.cs` — программное сохранение CSV, отчёта и графиков ScottPlot;
- `Task15Analysis.ipynb` — Polyglot Notebook для проверки данных и построения графика;
- `results/step-benchmarks.csv` — результаты выбора шага;
- `results/thread-benchmarks.csv` — результаты для количества потоков от 1 до 16;
- `results/thread-performance.png` — график времени и количества потоков;
- `results/single-vs-multi.png` — сравнение однопоточного и многопоточного вариантов;
- `results/optimal-result.txt` — итоговые параметры с пояснениями;
- `results/REPORT.md` — полный отчёт.

## Повторный запуск

Из корня репозитория:

```powershell
dotnet run --project task15\task15.csproj --configuration Release -- 3 16 task15\results
```

Параметры команды: количество повторов, максимальное количество потоков и папка результатов. Каждый вариант измеряется не менее трёх раз.

Notebook открывается расширением Polyglot Notebooks. Он использует библиотеку ScottPlot `5.1.59` и читает программно сформированные CSV-файлы без изменения путей.

Использована официальная инструкция [ScottPlot для .NET Interactive Notebook](https://scottplot.net/quickstart/notebook/).

## Полученный результат

- выбранный шаг: `1e-6`;
- оптимальное количество потоков: `15`;
- среднее однопоточное время: `1617,999 мс`;
- среднее многопоточное время: `190,761 мс`;
- ускорение: `88,21%`.

Результаты относятся к компьютеру с AMD Ryzen 7 5700X3D и 16 логическими процессорами.
