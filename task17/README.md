# Задача 17

`ServerThread` выполняет команды из потокобезопасной блокирующей очереди.

- `HardStopCommand` завершает поток сразу после выполнения команды остановки.
- `SoftStopCommand` выполняет оставшиеся в очереди команды и завершает поток.
- `UpdateBehavior` изменяет способ обработки следующей команды.
- исключения команд передаются в `IExceptionHandler`.

Если очередь пуста, поток блокируется и не выполняет активный опрос.
