# Задание 18

`ServerThread` принимает новые команды через потокобезопасную очередь. Длительные команды реализуют `ILongRunningCommand`: один вызов `Execute` выполняет один небольшой этап работы.

Незавершённая длительная команда возвращается в `RoundRobinScheduler`. Планировщик помещает её в конец своей очереди, поэтому длительные операции выполняются по очереди.

Когда новых и запланированных команд нет, поток ожидает сигнал `SemaphoreSlim` и не расходует процессорное время на пустой цикл.
