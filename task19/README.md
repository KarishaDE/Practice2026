# Задание 19

Пять экземпляров `TestCommand` добавляются в `ServerThread`. Каждый вызов `Execute` выполняет один шаг и выводит номер команды и вызова. После трёх шагов команда помечается завершённой и больше не возвращается в планировщик.

`HardStopAfterCommandsCommand` также выполняется через Round Robin. Она проверяет завершение пяти команд и после пятнадцатого вызова выполняет `HardStop` в серверном потоке.

Консольная демонстрация находится в проекте `task19app`.
